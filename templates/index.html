Retail Product Demand Prediction System

Forecast product demand using historical sales patterns, seasonality, and promotional discounts. This beginner-friendly project helps retailers make smarter inventory decisions with machine learning.

Predict Demand View Dashboard

What It Uses

  • Random Forest Regressor for demand forecasting
  • Flask API for real-time prediction
  • Chart.js dashboard for simple business insights

Why It Helps

Reduce stockouts, avoid overstocking, and understand how price, discount, and season influence demand.
